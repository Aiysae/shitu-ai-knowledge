# 势途AI企业级知识库

由Vantage万极维护并开源

Shitu AI Enterprise Knowledge Base collects documents, web pages and FAQs for source-cited answers, hybrid retrieval, agents, Wiki and MCP/API integrations.

The v0.1.0 release provides Web, Docker source builds and the built-in MCP server. Follow [deployment instructions](DEPLOYMENT.md), configure your own models and credentials, and create an account on first use. Desktop installers and independently published ecosystem packages are separate releases.

The distribution does not contain company data, runtime credentials or private folder sync scripts. File uploads do not automatically watch local folders.

See [README](README.md), [CLI compatibility](cli/BRANDING.md), [LICENSE](LICENSE), [third-party notices](THIRD_PARTY_NOTICES.md) and [NOTICE](NOTICE). Original authorship and source history are retained.
